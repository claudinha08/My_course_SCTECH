# Desafio Extra - SCTEC
Atividades e Desafios - Curso SCTECH

Este projeto faz parte do Desafio Extra do cursos de Introdução ao Data Science promovido pela SCTECH, tem como objetivo analisar
venda dos produtos e impacto das campanhas de promoção por região.

## Tecnologias utilizadas
- Python 3.x
- Google Colab
- Pandas
- Numpy
- Matplotlib
- Seaborn

## Arquivos do projeto
- Desafio_Extra_SCTECH.ipynb -> notebook principal
- requirements.txt -> bibliotecas necessárias
- bd_sample_superstore -> banco de dados
